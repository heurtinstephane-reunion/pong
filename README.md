# Pong 🏓

Petit jeu Pong jouable dans le navigateur, 100 % HTML/CSS/JavaScript, sans dépendance.

## Comment jouer

Ouvre le jeu ici : https://heurtinstephane-reunion.github.io/pong/

- **Souris**, flèches **↑ / ↓** (aussi **W / S**), ou swipe vertical dans la **bande tactile à gauche du plateau** pour bouger la raquette
- **Espace** ou clic pour lancer, mettre en pause ou rejouer
- Premier à **7 points** gagne
- **Effet** : si la raquette bouge au moment du contact, la balle part en "lift" léger à la manière du tennis (trajectoire incurvée, balle orangée)
- **Mobile** : le jeu se bascule automatiquement en mode paysage — tourne ton téléphone vers la droite (sens horaire) pour jouer ; le pull-to-refresh est désactivé et un bouton « Recharger » est disponible en haut à droite

## En local

Télécharge `index.html` et ouvre-le dans n'importe quel navigateur.

## Publication

Le site est publié gratuitement avec GitHub Pages : dans le dépôt, **Settings → Pages**,
choisir **Branch : main** puis **Save**. Le jeu est mis à jour automatiquement à chaque
modification de `main`.
